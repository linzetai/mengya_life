# MengYa 0.16A · Recording Semantics

基线 `0.16-morrow`；本包 `0.16A-morrow` / versionCode 22；数据库 v14（v13→v14 最小迁移）。

## 1. 进展数据链路（P0）

正式记录 `goal_checkins` 新增：

| 字段 | 作用 |
|---|---|
| `amount_kind` | `delta` 本次新增 / `snapshot` 累计快照 / `none` 定性进展 |
| `original_text` | 顾问记录时的来源原话，修改后仍可追溯 |
| `normalized_value` / `normalized_unit` | 仅在可可靠换算或继承时填写；原始 `metric_value` / `metric_unit` 不变 |

迁移 v14：
- 旧行默认 `snapshot`（保持原有“累计曲线”含义）；
- 能从 `record_proposals.applied_checkin_id` 回溯的顾问记录，回填真实类型、原话；
- 仍无法回溯的旧顾问记录按 `delta` 处理，避免被读成“累计总额下降”；
- 旧候选表 `amount_kind` 统一为大写枚举名（此前大小写混用会导致卡片读不出）。

轨迹（`GoalTrends` + 轨迹页）：
- 序列键改为 `(单位, 语义)`：**累计快照与增量绝不混线**；
- 增量块文案为“新增 / 最近一次新增”，并注明“仅表示每次新增，不是累计总额”；
- 累计块为“累计快照 / 最近一次累计”，纵轴为累计状态；
- “我看见的变化”对增量只写“N 次新增，最近一次 X”，不再写“从 2000 到 1500”。

单位：
- 有数值但缺单位 → 进入 `pendingFields=metricUnit`，确认按钮禁用，先让用户补；
- 单位可可靠换算（万元↔元、小时↔分钟）时，保留原始值与归一值；
- 不同单位、无单位各自成组，不静默合并。

## 2. 修改一致性（P0）

- 只改数值、说明仍是旧原话时，应用会把说明里的旧数字同步改写（2000→1500），并保留 `original_text` 作为“来源原话”，卡片折叠展示；
- 修改、撤销、重启后，卡片与正式记录保持一致；
- 撤销会删除对应 checkin 并将候选置为 `UNDONE`，不残留数值。

## 3. AI 回复与执行一致（P1）

- 系统提示改为：“应用支持对话式记录，但模型不能直接写库；不要在卡片确认前宣称已保存”；
- 提取期间聊天区显示“正在整理记录…”；提取失败给出真实提示，不伪造成功；
- 卡片状态是唯一写入事实：待确认 / 已记录 / 已取消 / 已撤销。

## 4. 定性进展（P1）

- `RecordIntentGate` 不再要求数字：完成、终于、面试、坚持、聊了、运动、复盘等也可触发；
- 无数值记录以 `amount_kind=none` 落库，不编造数值或完成状态；目标不确定时仍先澄清。

## 5. 卡片简化（P2）

卡片只保留：目标 / 本次进展 / 类型与数值 / 日期 / 状态 / 确认·修改·取消（或修改·撤销）；
来源原话默认折叠；标题不再重复目标名。

## 6. 备份与恢复

备份 v2 的 `goalCheckins` 增加可选字段 `amountKind`、`originalText`、`normalizedValue`、`normalizedUnit`；旧备份缺失时按列默认值恢复为 `snapshot`。恢复插入沿用动态列映射，无需改表结构。

## 7. 验证

单测：**321 项通过，0 失败**（新增 7 项语义测试 + 1 项备份测试）。

真机（QA 包，真实 `deepseek-flash`）：
- 两条增量 2000 / 1500：轨迹“新增”块 2000→1500，另一块“累计快照 · 元”147000，未混线（`01`、`02`）；
- 累计快照与增量分开显示，叙述改为“N 次新增，最近一次 500”（`03`）；
- 修改 2000→1500：卡片说明、数值、类型一致，来源原话保留（`04`）；
- 定性“今天终于完成面试了。”：生成待确认建议，无数值；选目标确认后写入，重启仍在（`05`、`06`）；
- 卡片简化与歧义候选（`07`、`08`）；
- 重启后语义、原话、类型均保留；数据库核对 `amount_kind=none/delta/snapshot` 正确。

未设备复测：断网/401/授权拒绝的失败提示；备份恢复的真机往返（仅单测覆盖字段保留）。

## 8. 已知限制

1. 增量仍以折线展示，但明确标注“每次新增”，不与累计混轴；后续可改柱状贡献图。
2. 说明改写只在“说明未变且包含旧数字”时发生；用户手改说明后以用户文本为准。
3. 旧 v13 数据只能通过候选表回溯语义；无候选的旧顾问记录按增量处理。
4. 备份恢复未在真机走完整往返；字段级单测通过。
5. 定性进展不进入数值趋势（无数值），只在目标进展历史中可见。
