# MengyaLife 0.15.3A · UI detail pass

基线：`0.15.3-morrow`，本包为 `0.15.3A-morrow` / versionCode 20，仍在 `master` 单工作树。未新增业务功能；未改数据库、AI 协议或授权语义。

## 修改与对应修复

### 目标编辑弹层（360dp / 1.3× 裁切）

- `GoalSheets.kt`：领域、状态 Chip 由单行 `horizontalScroll` 改为 `FlowRow`（横/纵间距 8/6dp，两侧各 4dp 内边距，叠加弹层既有 20dp 页边距）。所有选项完整换行展示，选中项无需横向滚动即可完整可见；不再出现“进行中”左侧被父容器裁切。
- 保持字段区独立滚动、保存/取消固定于滚动区外；360dp、1.0× 和 1.3× 下实测键盘弹出后，标题、描述、领域、状态、截止日期均可滚动访问，footer 完整位于键盘上方。
- 未改目标数据模型和保存逻辑。

### 设置/关于页

- `Common.kt` 的 `KeyValueRow` 改为稳定两列：标签 `weight(0.38)`，值 `weight(0.62)`、右对齐、无行数截断，允许长值自然换行；标签与值之间保留 12dp 间距，避免粘连、重叠或贴边。
- `SettingsScreen.kt`：显示品牌统一为 `MengYa Life`，标签改为“英文名称”；QA 信息仍只在 `BuildConfig.QA_BUILD` 分支展示。
- 未改 applicationId、数据库/备份技术标识。输入框、按钮、Chip 沿用现有统一圆角/边框/间距组件，未另起风格。

### 顾问页（不推翻既有 IME 修复）

- `AdvisorScreen.kt`：新增“是否跟随最新消息”状态。用户手动上滚阅读历史后，键盘开合、消息到达和布局变化不再无条件把列表拉到底；用户回到底部、或新消息到达时原本就在底部，才滚到末项。
- 保留既有 `adjustResize`、IME 时隐藏底部导航、单一 IME Insets 处理和紧凑键盘头部；顶部与状态栏、输入区与键盘不重叠。

### 深色主题实际发现并修复的缺陷

- 实测发现“人生全景”在深色模式仍显示浅色窗口底：该页面没有自己铺主题底色，透出了 window 背景。`MengyaLifeApp.kt` 根 `Box` 增加 `background(MorrowTheme.colors.canvas)`，深色全景现为完整深色，浅色不受影响。
