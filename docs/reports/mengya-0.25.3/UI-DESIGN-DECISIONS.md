# MengYa Life 0.25.3 · 设计决策

以下说明最终代码设计，不等同于全部真机验收通过。最后的恢复主操作修正已构建/单测，用户停止手机操作后未能真机复验；完整边界见 [UI-VERIFICATION](<UI-VERIFICATION.md>)。

## 1. 从“模型客户端”回到成长顾问

保留 0.25.2.1 自然 Handoff，未改回含 factId 或内部指令的技术气泡。普通对话不再逐条显示精确时间：按日期分组，完整时间与来源在“参考依据”内按需查看。配置与模型信息仍可展开查看；QA 离线状态始终明确标记，不伪装真实模型。

输入提示改为“说说近况…”，避免 320dp/1.3 时占位文字换成两行。现有 `LazyColumn`、用户上翻暂停跟随和 `imePadding` 机制保留，必须以真机长对话与键盘操作验证，而不是只观察短聊天截图。

## 2. 草案是可审核的行动，不是技术对象

- 待确认按行动名称 → 执行周期 → 关联目标排列；目标名称由当前目标快照解析，失效目标明确提示，不展示裸 ID。
- “保存计划”独占一行，是唯一主要操作；“编辑”“取消”下一行等宽、相同最小点击高度和圆角。
- 编辑采用独立全屏表单：常驻标签、多行字段、可滚动正文，底部并排操作避让键盘和系统安全区。键盘弹出时收起引导短句，为字段腾出空间；浅/深色系统栏图标同步主题。填写空标题时不可完成。
- “完成编辑”只更新草案，不创建行动；回到对话后再次“保存计划”才执行正式写入。
- 保存成功后直接折叠为简洁结果与“查看行动”，进入轨迹页，不再展开可再次保存的表单。

## 3. 今天只有一个视觉中心

已有确认行动优先于新的建议。主操作围绕当前行动的进展；建议为紧凑暖白卡片，深绿保留给重要操作和小标识，不再用整片深绿夺取首屏。问候不承担主任务，减小字号与装饰间距；信息量随真实数据变化，不用固定卡片高度迎合截图。

## 4. 洞察：可理解，也能质疑

详情顺序为结论 → 解释 → 展开依据与来源 → 讨论。独立事实完整保留；解释已逐字包含的事实正文不重复列出，仍显示引用数量并保留来源。目标、进展记录、日记等使用用户可理解的名称，技术类型及 factId 不直接展示。

来源变化后旧报告只允许在同一有效授权 epoch 的内存 UI 中保留供回看，明确过期、禁用讨论；撤权、授权 epoch 变化或未知授权来源时清除。重新评估接到 `InsightViewModel.generate()` → `InsightService.generate(force=true)`，不是只关闭提示或空回调。顾问草案来源错误时，卡内原“保存计划”主操作直接切换为“重新评估建议”，不再用强保存按钮与卡外弱重试争夺注意力；点击返回今天并真正重新生成。该 UI 状态不修补来源指针，也不授权旧草案，写入仍必须通过既有来源校验。

## 5. 轨迹先讲发生了什么

最近的实际记录变化先于图表解释；进展次数、行动状态、数字事实图表、时间线分层。多行动可展开，顶部可跳到行动状态。累计快照与单次增量不混算；只有一个点时不编造趋势，近周/近月计数均按对应时间窗计算并排除未来记录。合并重复的“真实数据/亲手记录/来源”宣讲，保留必要口径说明。

## 6. 共同视觉约束

- 延续暖白 / 深绿及对应深色体系，不引入蓝紫渐变。补齐 Material 3 新版 surface container 色彩角色，避免详情弹窗悄然回落到默认紫灰容器；不是只给某个截图单独染色。
- 页面卡片沿用 20dp 圆角，嵌套聊天草案 14dp，按钮 14dp。
- 主次按钮最小高度统一为 52dp，内容可随字体增高，绝不强制固定高度；紧凑文字操作仍保留系统可触达区域。
- 间距采用 4/8/12/16/24dp 的层级，标题、正文、元信息使用现有 Morrow/Material typography，时间来源降一级而非删去。
- 320/360/412dp 与字体 1.3 以实际运行检查；长文本换行、表单滚动，不使用固定高度裁切解决单张截图。

## 7. 正确性补丁边界

`GoalRecordApplyService` 新增受信验证入口：在 Restore write barrier 与 Room 事务内重新读取草案、判断来源、执行来源 validator，之后才允许 CREATE / UPDATE / BREAKDOWN 写入。来源草案不能绕过普通 apply；缺失/损坏来源与缺 barrier 均 fail-closed；失败回滚、成功幂等。复用既有授权与恢复机制，不迁移 schema，不重构 AI 授权、恢复或备份。

## 8. 验收边界

QA 合成数据只能证明界面/持久化流程；本轮不以离线 QA 聊天证明真实模型体验。自动测试、真机视觉、真实模型质量分别记录。交付后等待独立 UI 验收，不主动进入 0.26。
