# MengYa Life 0.25.3 · UI 审查

基线：`master / 9a19932d21a375679fdfad4e93e8db43f6cff019`（0.25.2.1）。
范围：顾问、草案、今天、洞察详情、轨迹；不重构已稳定的 AI 授权、恢复、备份。

## 修改前的主要问题

| 页面 | 观察到的问题 | 优先级 / 处理方向 |
|---|---|---|
| 今天 | 320dp/1.3 时问候与大面积深绿建议占据首屏，已确认行动及其操作被推后；建议与计划竞争焦点 | P1：行动优先，建议降为紧凑纸色观察卡，压缩标题与装饰留白 |
| 顾问 | 来源按钮、逐条尾部时间、结果卡形成碎片化层级；模型配置胶囊偏技术客户端 | P2：按日分隔，精确时间收入按需详情；来源弱化且可追溯；真实模型名称收入展开设置 |
| 计划草案 | “记下这个计划/修改/放弃”混排；点击区域不统一，周期与目标弱；成功态“查看”对象不明确 | P1：保存计划唯一主操作；编辑/取消等宽次操作；结果明确“查看行动” |
| 草案编辑 | 窄弹窗字段只有值没有常驻标签；编辑保存与正式确认语义混淆；空间利用不佳 | P1：独立全屏、可滚动表单；字段标签、说明、完成编辑与放弃修改明确分开 |
| 洞察详情 | 正文与规则事实逐字重复；GOAL/CHECKIN/记录编号裸露；讨论操作在目标/趋势之后且同权 | P1：结论→解释→按需依据→主讨论；友好来源名称；保留全部独立证据 |
| 失效来源 | 缺少明确可执行的重新评估路径 | P1：旧结论标识失效并禁讨论；重新评估实际调用 force=true 的生成流程 |
| 轨迹 | 首屏偏数据说明、图表；最近实际变化较后，行动状态与次数/事实重复描述；近月日记统计口径存在偏差 | P1：最近变化优先；次数、行动、事实图表、时间线分层，并修正范围统计 |

## 审查规则

每张新截图检查：无效留白、重复内容、主操作、次操作、截断、遮挡/横向溢出、个人成长顾问定位。滚动视口边缘暂未显示内容不直接判为永久遮挡；须实际滚动到末端验证。键盘验收须同时核实系统 `mInputShown=true`，不能用文件名声称键盘存在。

设备截图中可见宿主 DSH 的顶部状态与右侧宠物悬浮层。这些是外部覆盖，不能当作 MengYa 自身绘制，也不能用裁图掩盖；其可能遮住局部文字，须在独立验收时注意。

## 最终审查
