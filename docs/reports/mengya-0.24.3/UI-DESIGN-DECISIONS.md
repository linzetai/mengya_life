# MengYa Life 0.24.3 · 设计决策

## 1. 目标与约束

产品不是任务管理器，也不是数据看板。本轮所有页面都围绕同一条链路：
真实记录 → 成长记忆/趋势 → AI 发现问题 → 用户确认 → 行动 → 新记录。

约束：
- 不新增第三方依赖，不引入图表库；
- 不改数据库 schema，不动备份/恢复/Agent/Care 状态机（恢复只改成功文案）；
- 保留真实数据来源（Room / DataStore / Keystore / 本机规则）；
- QA 与正式包继续隔离。

## 2. 今天页：三层信息

```
MengYa + 设置                       ← 品牌与唯一全局入口
─────────────────────────────
日期 + 一句问候                       ← 时间感，不抢焦点
[当前关注]  一个可核验的发现/记录/空态   ← 视觉焦点
[下一步]    唯一主按钮 + 最多两个文字级次操作
[成长概览]  方向数/阶段数/日记数 + 2 条方向摘要 → 全景
写日记 · 探索方向 · 讨论一个决定        ← 文字级入口，不占主视觉
```

决策：
- **只保留一个主按钮**。主动关心出现时，「下一步」就是关心卡，避免与洞察卡
  抢注意力；小计划并入同一条决策链。
- **空态不假装**。没有任何记录时，焦点卡用浅色卡片而不是深绿洞察卡，
  文案为「还在认识你」，行动是「和 MengYa 聊聊」，不生成任何判断。
- **10 秒可读**。首屏只有两个带背景的信息块（关注 + 下一步），其余是文字与列表。
- **成长概览只做摘要**。方向最多 2 条；超过两条给「还有 N 个方向」，
  点击进入人生全景，不在首页展开目标树。

信息优先级实现为纯函数 `decideTodayNextStep`，便于单测与后续调整。

## 3. 顾问页：对话优先

- 顶栏只保留「顾问 + 设置」；状态压缩成一个胶囊（已配置 · 模型 / 等待授权 / 未配置模型）。
- 空对话时不再显示大标题，直接进入「从一句话开始」的引导与 3 个建议。
- 状态详情只在用户点开胶囊时出现；说明「发送消息时才会发起真实请求」，
  **不再显示「已连接」**。
- 输入框固定在底部，随 IME 收缩消息区；发送/取消/失败重试保持原位。
- 记录建议、来源、目标草案仍以卡片附在对应消息之后，不进入对话主体。

## 4. 轨迹页：回答「这段时间我有什么变化」

三段结构：

1. **数值变化**：按单位/目标分别绘制真实 `goal_checkins`；单点只画点；
2. **这段时间的变化**：数值、最近进展、日记数量，跟随时间范围；
   末尾是一周回顾入口；
3. **线索与回溯**：本机回顾事实、最近日记、最近目标，均可点回原文。

时间范围（一周/一月/三月）只影响可核验的记录窗口；不生成「成长指数」。

## 5. 人生全景：所有领域可达

- 领域不再 `take(4)`；按用户创建顺序分组；
- 领域头可折叠，默认展开前两个；顶部提供「全部展开 / 全部收起」；
- 领域摘要显示「N 个 · 已完成 M」；
- 从今天页点某个目标时：展开其领域、展开父级路径、滚动到该领域；
- 底部保留「新增长期目标 / 探索方向」两个真实入口。

## 6. 日记页

- 保留「写一篇日记」大卡片 + 月份分组 + 日期块；
- 日期使用 `rememberToday()`，跨午夜/回前台自动更新；
- 编辑器仍是单一多行文本 + 可选标题，不引入富文本；
- AI 线索与手动记录在「线索」区独立标记，不混排进正文。

## 7. 设置与恢复：文案即承诺

- 恢复流程文案严格对应实现：
  选择文件 → 口令校验 → 预览覆盖范围 → 勾选风险 → 确认执行 → 结果。
- 成功文案由 `RestoreCoordinator` 按 `RestoreCredentialPolicy` 生成：
  endpoint 未变 → 保留 Key 与授权；endpoint 变化 → 删除旧 Key、撤销授权；
  备份未携带 endpoint → 保持本机配置。
- 设置页联网说明列出三种真实请求来源（对话 / 每周 AI 回顾 / 主动关心）。
- 通知说明改为真实行为，并跳转系统通知设置。
- 未实现的能力（删除全部数据）继续明确标注，不做空操作。

## 8. 组件与设计令牌

沿用 `MorrowTheme` 与 `MorrowSpacing`，不新增颜色体系：

| 角色 | 令牌 |
|---|---|
| 页面底色 | `colors.canvas` |
| 卡片 | `colors.card` + 1dp `hairline` |
| 强调/森林绿 | `colors.forest` / `colors.accent` |
| 洞察卡 | `colors.insightCard` + `insightText` |
| 标题 | `MorrowType.Display / SectionTitle` |
| 正文 | `MaterialTheme.typography.bodyMedium/Small` |
| 圆角 | 16dp 卡片 / 22dp 洞察卡 / 999dp 胶囊 |
| 页面边距 | `MorrowSpacing.PageHorizontal = 22dp` |

共享组件：
- `StatusChip(GoalStatus)` 从旧 GoalsScreen 提到 `Common.kt`，目标页与全景共用；
- `rememberToday()` 放到 `Common.kt`，今天页与日记页共用；
- 删除 `DemoTag` / `PageHeader`（只服务已删页面）。

## 9. 响应式与可达性

- 底部导航改为 `weight(1f)` 等分 + 48dp 最小高度，320dp 与字体放大不溢出；
- 卡片文字 `maxLines` + 省略，避免固定高度截断中文；
- 长列表全部使用 `LazyColumn`，今天页保持两个信息块以控制滚动距离；
- 深色/浅色共用同一套语义令牌，洞察卡在深色下使用 `MorrowDark.InsightCard`。

## 10. 取舍

- **没有重做视觉语言**：继续暖白/森林绿/衬线标题，避免用户重新学习。
- **没有新增图表库**：真实趋势只有折线 + 数据点，自绘已够用。
- **没有把 AI 变成页面主体**：AI 结果只在有可核验事实时出现，失败时退化为本地事实。
- **没有删除测试入口**：QA 横幅、离线引擎、AdvisorTestBus 保留，正式包不渲染。
