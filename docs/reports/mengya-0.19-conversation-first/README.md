# MengYa 0.19 · Conversation First & Growth Review

基线 `0.18-morrow`；本包 `0.19-morrow` / versionCode 26。数据库不变（v16），无破坏性迁移。

## 一、P0 顾问页空间重构

### 顶部
- 保留「顾问」与设置入口。
- 删除「继续这段对话」。
- 删除常驻的大连接/授权卡，改为一行紧凑胶囊：状态点 +「已连接 · 模型」+ ⌄。
- 点击胶囊才展开完整信息（模型、授权读取范围、设置入口）；未配置/需授权时显示红色状态点，且原有授权面板仍会出现。
- 空会话时保留一句引导语，进入对话后不再占位。

### 底部
- 移除常驻的「整理为目标草案」大卡片。
- 改为输入框左侧轻量「＋」菜单，内含「整理为目标草案」；功能保留，正常状态不占空间。
- 输入区只保留输入框与发送按钮；键盘关闭时才有底部导航（沿用 IME 逻辑）。

### 历史提案折叠
- 待确认卡片保持完整信息与操作。
- 已确认/已放弃的提案折叠为 1–2 行结果，例如「✓ 已创建目标：每天散步　查看」；点击「查看」展开原卡片与操作。
- 目标、日记、进展三种提案共用同一折叠逻辑。

### 实测空间变化（同一设备 1200×2608，同内容）
- 0.18：顶部约占 ~640px（标题 + 继续 + 状态卡），底部提案卡约占 ~180px，可读区约 58%。
- 0.19：顶部约占 ~300px，底部仅输入区，可读区约 73%（按截图元素边界估算，非遮挡凑数）。
- 键盘打开：导航栏隐藏，输入框贴合 IME，无重叠、无大面积空白（`03`）。

## 二、P1 对话式成长回顾

- 用户主动说「帮我回顾这周/目标推进怎么样」即可；不新增后台调用、不新建线程。
- 系统提示新增回顾规则：先给「记录里实际发生的事实」→「值得注意的变化（标明是观察）」→ 1–3 条建议；最后最多一个问题；没有记录就直说，不编造。
- 真实模型实测（`06`）：正确引用阅读页数、跑步 5 公里、存款 500、面试日记，先说明日期局限，再给三条建议；未生成任何目标/进展卡，未自动写入。
- 授权逻辑不变：只在已授权类别内读取目标/进展/日记/历史。

## 三、P2 小范围补足

- 拆解取消勾选：卡片支持逐条勾选，`GoalRecordApplyService` 只创建选中项（本轮未重新走真机勾选，见未完成）。
- 拒绝拆解记忆：会话内记录被放弃的拆解目标 id，后续目标提取提示词明确不再重复建议该目标的拆解。
- 相近目标提示：新建目标与已有目标标题高度相似时，草稿“还不确定”中标注「与已有目标「X」相近，请确认是否同一个」；完全同名直接不重复创建。
