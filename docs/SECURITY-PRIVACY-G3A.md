# Gate 3A 安全与隐私说明

## 1. 权限

Gate 3A 只新增一个权限：

```xml
<uses-permission android:name="android.permission.INTERNET" />
```

用途：把用户主动发送的问题（以及用户确认附加的目标摘要）直接发送到
**用户自己填写的 OpenAI-compatible 服务地址**。

- 没有自有后端，不经过萌芽人生服务器；
- 不申请存储、通知、位置、通讯录、相机等权限；
- `android:usesCleartextTraffic="false"`，只允许 HTTPS。

## 2. API Key 存储

- 使用 **Android Keystore** 中的 AES-256/GCM 密钥加密，密钥不可导出；
- 密文（Base64 IV + 密文）存入独立的 DataStore：
  - 正式包 `mengya_ai` / 别名 `mengya_ai_key`；
  - QA 包 `mengya_ai_qa` / 别名 `mengya_ai_key_qa`；
- Room 中**没有** key 字段；日志、崩溃提示、导出文件不包含 key；
- UI 使用 `PasswordVisualTransformation`，保存后不再回显；
- 「删除密钥」会同时：
  1. 删除 DataStore 中的密文；
  2. 删除 Keystore 中的别名；
  因此旧密文即使被恢复也无法解密，旧 key 不能再被使用；
- 单元测试用假加密器验证「存储不含明文、删除后 runtime 为 null」；
- 真机测试用 QA 包写入测试 key，检查 DataStore 文件、Room、应用进程日志、
  导出 JSON 均不含明文。

> 调试签名 `keystore/mengya-debug.keystore` 的口令是公开的 `android`，
> 它只用于开发/测试覆盖安装，**不能用于发布**。

## 3. 默认发送 / 不发送

每次请求**默认只发送**：

- 当前用户输入；
- 最近 12 条对话（字符预算 6,000，超限截断）。

默认**不发送**：

- 日记正文；
- 全部长期目标；
- 全部进展记录；
- 完整数据库；
- 其它应用数据。

可选目标上下文：

- 用户在顾问页明确选择一个长期目标；
- 发送前弹出「本次将发送哪些个人数据」，列出目标名称、描述、阶段/行动数量、
  最近进展摘要，并明确「不发送：日记正文、其它目标、完整数据库」；
- 用户点「确认并发送」后，才把该目标的摘要加入本次请求；
- 取消则不发送；
- 上下文只作用于当次请求；重试不会自动重复发送目标摘要。

## 4. 网络边界

- 只支持 HTTPS；不跟随重定向；
- 请求只包含模型、消息、`max_tokens`、`temperature`、`stream=false`；
- 不发送工具调用、图片、文件或系统提示以外的隐私数据；
- 服务地址与模型名称保存在本机 DataStore（非敏感）；
- 用户填写的服务地址会被展示（域名），但 key 不会。

## 5. 数据导出

- 导出 JSON 仍只包含日记、目标、进展；
- **不包含** API 配置、key、聊天记录或请求日志；
- 导出文件本身可能含敏感日记内容，需用户妥善保管（Gate 2C 已有提醒）。

## 6. 已知风险

1. **服务方可见内容**：用户选择的模型服务会收到问题与（授权后的）目标摘要；
   其日志/留存政策由服务方决定。
2. **无证书固定**：依赖系统信任链；企业代理/恶意 CA 仍可能截获。
3. **设备被攻破**：Keystore 能防止离线读取，但不能抵御已取得应用运行权限的攻击者。
4. **调试签名**：调试包可被替换安装；正式发布必须换发布签名。
5. **QA 离线测试引擎**：只在 QA 构建中可用，回复明确标注「QA 离线测试引擎」，
   正式包不会创建它。
6. **聊天记录不导出**：本轮导出不含 `advisor_messages`，用户卸载应用仍会丢失聊天；
   后续可设计加密导出/导入。
